How to use

  1. Edit the file /stores/<slug>/index.html or replace it with a generated page from your data.
  2. Push the repository to GitHub and enable GitHub Pages (branch: main, folder: / (root) or /docs).
  3. Each store page is a plain HTML file and is printable. Add a CNAME or DNS record later if a store wants its own domain.
