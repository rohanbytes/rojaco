Make your store stock visible, verifiable and printable

Rojaco helps retail medical shops publish weekly stock listings in the format required by authorities. No backend — edit a data file and push to GitHub.

Stores

This is an MVP sample — store pages are static HTML and generated from JSON data. Each store gets a URL you can share or point a custom domain at.

How the MVP works

  1. Store data lives in data/stores.json. To update stock: edit the store's items list and push to GitHub.
  2. Each store has a static page at stores/<slug>/ ready to print for authorities.
  3. No server required — host on GitHub Pages.
